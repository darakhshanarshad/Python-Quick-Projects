# Python Quick Projects

This repository contains my beginner-level Python projects, created to practice programming fundamentals, problem-solving, conditions, loops, strings, functions, and user input.

## Projects

### 1. Username Generator

A simple program that generates usernames based on user-provided information.

### 2. Password Validator

Checks whether a password meets basic requirements such as length, numbers, uppercase/lowercase letters, and special characters.

### 3. Purchase Bill Calculator

Calculates the total purchase bill based on item prices and quantities.

### 4. Email Generator

Generates an email address using information provided by the user.


### 5. OTP Generator & Verifier

Generates an OTP and allows the user to enter the OTP for verification.

## Purpose

These projects are intentionally simple because they represent my **early-stage Python practice**. My goal is to strengthen programming logic by building small programs independently before moving toward larger projects.
